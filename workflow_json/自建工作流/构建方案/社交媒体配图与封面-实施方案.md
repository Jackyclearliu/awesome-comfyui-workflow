# 社交媒体配图与封面工作流 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付一个可实际运行的 ComfyUI 单工作流，支持 AI/本地底图切换、精确输出尺寸、三处独立文字和可调图片水印。

**Architecture:** 复制并保留现有 Qwen Image 2.1 Turbo 文生图子图，在外部增加尺寸治理、惰性来源切换和最终画布适配。文字与水印均在最终像素画布上后期合成，避免模型采样影响排版精度。

**Tech Stack:** ComfyUI 画布 JSON、Qwen Image 2.1 Turbo、KJNodes、LayerStyle、Goohaitools、rgthree、现有工作流分析与 ComfyUI HTTP API。

## Global Constraints

- 首版不创建自定义节点，不自动下载 URL，不让模型生成正式文字。
- 最终输出尺寸是排版的唯一基准；模型尺寸使用 32 倍数，最终输出恢复精确目标像素。
- Turbo 采样固定为 `cfg=1`、`euler` 和 9 步 sigma：`1.0, 0.978453, 0.954180, 0.926626, 0.895080, 0.845148, 0.704534, 0.414568, 0.150000, 0`。
- 本地图片模式不得执行采样或加载生图模型；子图内保留的提示词 PreviewAny 可以独立执行。禁用的文字模块必须透传上一层 IMAGE。
- 默认字体为 `Alibaba-PuHuiTi-Heavy.ttf`，默认水印为 `20261115-moxian-watermark-INKLINE-white-1200x400.png`。
- 不修改模板原文件，不提交 Git，不新增测试脚手架文件。

### Task 2: 接入尺寸、底图来源和最终画布适配

**Files:**
- Modify: `workflow/workflow_json/自建工作流/社交媒体配图与封面.json`

**Interfaces:**
- Consumes: Task 1 子图实例 IMAGE 输出。
- Produces: 唯一的目标宽度 INT、目标高度 INT，以及精确目标尺寸的 `base_image` IMAGE。

- [x] **Step 1: 添加尺寸控制**

使用 `GoohaiRatioAndResolution` 作为统一尺寸节点，连接方式如下：

- 默认 `比例=自定义宽高`、`自定宽度=1880`、`自定高度=800`、`倍数取整=0`，得到精确公众号封面尺寸。
- 16:9 配置为 `比例=16:9`、`模式=固定宽度`、`固定边像素=1920`，输出 1920×1080。
- 2:1 配置为 `比例=2:1`、`模式=固定宽度`、`固定边像素=2000`，输出 2000×1000。
- 在尺寸组添加 MarkdownNote，完整记录上述三种配置及自定义模式，避免增加多套切换节点。
- 将节点宽度、高度输出直接提供给最终适配节点。
- 另加 `SimpleMathDual+`，将目标宽、高分别接入 `a`、`b`，`value_1=round(a / 32) * 32`、`value_2=round(b / 32) * 32`；`int_1`、`int_2` 连接生成子图的宽、高输入。这样模型使用 32 倍数尺寸，最终适配仍使用未经取整的精确目标尺寸。

- [x] **Step 2: 添加本地图片和惰性来源切换**

添加 `LoadImage`，默认图片为 `黄仁勋演讲网图.png`。添加 `LazySwitchKJ`，`switch=True` 时 `on_true` 接 Qwen 子图 IMAGE，`on_false` 接本地 LoadImage IMAGE。开关标题写明“开启=AI 生成；关闭=本地图片”。

- [x] **Step 3: 添加最终底图适配**

使用 `ImageTransformKJ`，输入接 LazySwitch 的 IMAGE，目标宽高接尺寸节点。默认使用保持比例的裁满模式、居中裁剪、`divisible_by=1`；需要补边时使用同一节点的 pad 模式，禁止拉伸变形。将结果命名为 `base_image`，作为后续所有文字模块的唯一底图来源。
